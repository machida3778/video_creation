# 音楽で見せるランキング: 台本

ナレーションなし。**10位から**1位まで、`route.params.items`（既定10、5〜10）件を重複なく並べる。
15位・16位から始めない（2026-11-10 ユーザー指示: 長すぎる）。
`script.lines` は1項目1行で、`text` は画面に出す名前だけ（例「ナツミート（現）」）。
`Script` の既定の `cast: {narrator: ""}` と話者キーを保持するが、音声ID・yomi・読み上げは不要。
任意で最初に0.8〜1.2秒のタイトルカード用の行（例「〇〇最強ランキング」）を追加する。
5位の直前に `route.params.top_card`（既定「Top」）と同じ `text` の行を追加し、約1.5秒の区切りにする。

## 自信をもって言い切る（2026-11-10 ユーザー指示）

ランキングはエンターテインメント。「独断で決めた」「根拠はない」「勝手に」「個人的な」「異論は認める」
のような保険は面白さを損なうので、タイトル・カード・表紙・説明文のどこにも書かない（QA の `confidence` が止める）。
タイトルは「〇〇最強ランキング、1位は？」のように堂々と言い切る。順位は作り手の選定として示せばよく、
断り書きはいらない。ただし数値（登録者数・売上など）を出すときは調査し、`research.json` の根拠を
該当行の `fact_ids` から参照する。出典のない数値を事実として書かない。

通常は各項目約3.4秒、1位は溜めと閃光の演出を含めて約6秒（`route.params.first_sec`）。
カードを含む総尺を30〜59秒（目安40秒前後）に収める。
