# 音楽で見せるランキング: 台本

ナレーションなし。N位から1位まで、`route.params.items`（5〜20、通常10〜16）件を重複なく並べる。
`script.lines` は1項目1行で、`text` は画面に出す名前だけ（例「ナツミート（現）」）。
`Script` の既定の `cast: {narrator: ""}` と話者キーを保持するが、音声ID・yomi・読み上げは不要。
任意で最初に0.8〜1.2秒のタイトルカード用の行を追加する。
5位の直前に `route.params.top_card`（既定「Top」）と同じ `text` の行を追加し、約1.5秒の区切りにする。

主観的な順位はタイトルや説明にそう明記する。順位が事実を主張するときだけ調査・出典確認を必須とし、
`research.json` に根拠を記録して該当行の `fact_ids` から参照する。根拠なしに強さや人気を客観的事実として断定しない。
通常は各項目約3.4秒。カードを含む総尺を30〜59秒に収め、件数が多ければ `item_sec` を短くする。
