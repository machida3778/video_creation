# 掛け合い解説: 台本の書き方

**視聴者の疑問を、二人の会話で1つ解く。** `docs/SHORTS_CRAFT.md` に従い、自然な疑問・根拠・納得の順に進める。

## 二人の役割

- `config/characters.yaml` の `questioner`（ポンカ）と `explainer`（リリモ）を使う。`script.json` の `cast` は `{questioner: vv_zundamon, explainer: vv_metan}` のように、各キャラクターの `voice_id` と一致させる。話者は `Line.speaker` に役割名で書き、キャラクター名や音声名に置き換えない。
- **聞き役→解説役の交互のターン** にする。同じ話者の行を続けない。聞き役は視聴者の疑問・よくある誤解・反例を短く出す。単なる相づちを重ねず、話を一歩進める。
- 解説役は事実と仕組みで答え、事実を述べる行に必ず `fact_ids` を付ける。`research.json` の事実から `source_ids` を通じて一次資料にたどれること。聞き役が事実を述べるときも同じ。
- 誤解は「〜だと思ってた」「〜じゃないの？」のように疑問として提示し、次の応答ですぐ正す。出典のない断言を聞き役に言わせたままにしない。
- 音声の利用条件は立ち絵の許諾を含まない。既存作品やVOICEVOX公式キャラクターの口調・設定・立ち絵を借りず、レジストリのオリジナル二人として話す。声のクレジットは別途必要。

## フックから納得まで

- フックは **4案以上、3種類以上の型**（問い／誤解の指摘／数字／意外な主張など）を考え、採用案を聞き役の1行目に、候補を `hook_options` に残す。0秒から話す。挨拶・自己紹介・「今回は〜」を入れない。
- 冒頭の疑問は本編で必ず回収する。聞き役が疑問を掘り下げ、解説役が数字や比較、具体例を使って段階的に説明する。1本に話題を詰め込みすぎない。
- 50秒以上なら30〜40秒で、新しい疑問や反例による引き直しを1回入れる。
- **最後に納得できる答え（payoff）** を置く。最後の短いやり取りで誤解がどう変わったかを示し、冒頭の疑問に答えて切る。メタな制作話、「この動画では」「視聴者のみなさん」、中身のないボケ・ツッコミ、長い相づちは入れない。CTAは最大1つ。

## 行の書き方

- `vg/schemas.py` の `Script` に合わせる。**1行1発話、24字以内（句読点を含む）**。長い説明は別の疑問への応答に分け、交互のターンを守る。字幕は最大2行、1行10〜15字を目安にする。
- 普段の話し言葉で、二人の語尾を無理にキャラ付けしない。1行ごとに新しい情報か疑問を入れ、同じ説明の言い換えで尺を延ばさない。
- 声は約8字/秒、VOICEVOXはspeedScale 1.3前後、行間は詰める。必要な間だけ `pause_after`。固有名詞・略語・数値の読みは行全体の `yomi` で指定する。
- `emphasis` は1行1語まで。主要な検索語を `search_query` に1つ指定する。出典の範囲を超える断定、架空の体験談、健康やお金の助言は避ける。
